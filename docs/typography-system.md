# Typography system

Room for Mama uses two typefaces with fixed roles.

- Fraunces is reserved for display, page title, section title and heading roles. It uses `SOFT` 100 and `WONK` 1.
- Figtree is used for body copy, controls, labels, captions and times.
- Body and controls use 17/26. Controls use weight 600.
- Captions use 13/18 at weight 600. Uppercase eyebrows use the same scale without added letter spacing.
- Compact supporting copy uses 15/22. The calendar alone may use the 12/15 micro scale where its fixed grid requires it.
- Times use weight 600 with tabular numerals.
- Responsive page titles use 40/44 on small screens and 72/76 from tablet widths.
- One-off sizes remain only for intentional display artwork, such as the founding-price sticker.
